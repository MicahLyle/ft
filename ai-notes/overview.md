# AI Overview

This is, first and foremost, an experimental project and a prototype. This is not production code, and you can assume it doesn't ever need to be.

That being said, code should be structured and organized well. I do not care, in this context, about it being organized into multiple files. In fact, single files are easier. However:
* I expected Python code to, as necessary to keep things clean, neat, organized, polished, etc., properly split functionality into classes, methods, functions, decorators, context managers, generators, etc.
* I expect JS code to do similarly.
* I expect Vue code to use a lot of components, and clearly comment and define which each component is for. This is the most important to keep clean and organized.
* Please only comment as necessary, but when you do comment, use full english sentences and I prefer periods at the end, etc.

## Important

When writing code, please figure out what today is (call code if necessary to do so), and create or append to a properly named markdown file in the `ai-notes` folder about what you did and why you did it. Include context on how you were prompted as well.

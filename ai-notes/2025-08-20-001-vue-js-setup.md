What I did
- Added a root `<div id="app">` wrapper to the in-memory `index.html` template in `app.py` and included `<script type="module" src="/app.js"></script>`.
- Created `public/app.js` that imports Vue 3 from the CDN ES module build and renders a simple Hello World with plus/minus buttons to modify a counter.

Files touched
- `app.py` → updated `app.templates["index.html"]`
- `public/app.js` → new ES module

How to use
1. Start your NanoDjango app as usual.
2. Visit `/` in the browser. The page is served over HTTP, which is required for native ES modules (not `file://`).
3. You should see "Hello World" and +/- buttons that change the count.

Notes
- This follows Vue's CDN + native ES modules approach from the Quick Start guide: `https://vuejs.org/guide/quick-start.html`.
